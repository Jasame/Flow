## 二、候选语料筛选与去重原则 (Screening & Deduplication)

### 1. 筛选标准 (Selection Criteria)
- **可追溯性与真实性**：每一篇材料均锚定真实世界的公开权威语料来源，保留直接访问链接、获取时间及授权协议。
- **教学适配度与认知负荷**：严格控制文本篇幅与生词密度，A2材料句式控制在简单句与基础情态句，B1材料适度引入学术规范与职场沟通逻辑，B2材料体现长难句切分与辩证思维。
- **Flow 学习闭环契合度**：材料必须包含清晰的教学目标与潜在认知障碍点（如时间数字混淆、转折词忽律、表象与本质混淆、痛点与商业价值混淆），为后续的“诊断-分流-补练-验证”提供坚实基础。

### 2. 去重与情境家族控制 (Family ID Management)
- 为避免同质化情境堆砌，采用规范的 `family_id` 体系（如 `FAM-CAMPUS-STUDYGROUP`, `FAM-DAILY-APPOINTMENT`, `FAM-CET-PSYCHOLOGY` 等）。
- 每一个 `family_id` 仅用于承载同情境下的平行变体或验证练习，确保20篇候选材料在具体场景、核心词汇和任务目标上互不重叠。
- 经自查比对，20篇材料在主题场景、人物关系、情节走向上实现了100%正交去重，无任何重复材料或抄袭题干。

## 三、5组高完备练习包（Flow Learning Packs）设计说明

本批次精选的 5 组完整练习包均严格遵循 Flow 的教学闭环：  
`起始题 (Initial Diagnostic) → 错误归因 (Error Hypotheses) → 短题诊断 (Distinguishing Check) → 针对性短讲解与补练 (Remediation Branches) → 新语境验证 (New Context Verification)`

### 练习包概览与教学目标映射

| 练习包ID | 对应候选ID | 主题与情境 | 建议等级 | 核心诊断学习目标 |
| :--- | :--- | :--- | :--- | :--- |
| **FLOW-PACK-001** | FLOW-CAND-001 | 校园学习：学术中心活动通知 | A2 | 听懂时间表达并准确绑定至对应活动（区分数字听音与主谓绑定） |
| **FLOW-PACK-002** | FLOW-CAND-006 | 日常沟通：牙科门诊改约电话 | A2 | 排除客满/冲突时段，识别委婉否定与最终敲定确认信号 |
| **FLOW-PACK-003** | FLOW-CAND-011 | 四六级：拖延症与情绪调节 | B1 | 识别“先破后立”转折信号词，区分大众普遍误区与科学核心论点 |
| **FLOW-PACK-004** | FLOW-CAND-016 | 职场沟通：跨时区项目周会邮件 | B1 | 结合多地时区换算锁定参会时间，区分会议时间与异议反馈截止时限 |
| **FLOW-PACK-005** | FLOW-CAND-020 | 职场沟通：数据软件采购申请 | B1 | 在商务提案中区分现状痛点/产品功能与量化投资回报（ROI）论据 |

### 重点关注：第一包（FLOW-PACK-001）专项对齐审查
按照任务指导书明确要求，第一包实现了高度精细化的分支诊断：
1. **起始题设计**：考查 Academic Writing Workshop 举办时间（周五上午 10:30）。
2. **两条待验证原因**：
   - **H1 (时间表达没有听清)**：如将 10:30 (ten thirty) 误听为 10:13 (ten thirteen)。
   - **H2 (听到了时间，但没有对应到正确活动)**：如误选了前文周四 3:15 PM（属于 English Discussion Group）。
3. **精准短题诊断**：
   - 短题1（针对H1）：单独提取 10:30 的短音频，考查纯粹的数字听辨；若错，触发 **Branch-1（-teen 与 -ty 重音辨析）**。
   - 短题2（针对H2）：考查双活动文本主谓绑定；若学生短题1正确但初题选错，触发 **Branch-2（主谓时间绑定法则）**。
4. **两套独立补练与反馈**：各分支配备2-3分钟的精讲与1道靶向微练。
5. **新语境验证题**：构建全新的计算机机房与数字图书馆迎新通知（IT Support Center），使用全新时间（周二 1:45 PM vs 周四 3:30 PM）验证同等能力，保证未在先前提示中泄露答案。

## 四、逐项自查清单与核验结论 (Self-Audit Checklist)

在语料交付前，已对全部材料执行了逐项审查：

- [x] **来源是否实际访问与记录**：20个来源均通过脚本或浏览器实际核查，网络状态（如 200 OK、403、Timeout）已如实写入 `sources.csv`。
- [x] **内容类型标注意图清晰**：明确标注“根据来源改写的教学材料”、“根据来源事实原创编写的教学材料”、“完全原创的情境练习”；四六级原创练习统一添加“四六级原创模拟练习”标识。
- [x] **版权与许可合规性**：明确区分了 CC BY-SA 4.0、CC BY 4.0、CC BY-NC-SA 4.0、Public Domain 等开放授权；对 British Council 等商业保留版权来源，采取事实提炼与AI独立重写，标明待审核确认。
- [x] **去重与同质化检查**：四大主题场景丰富，覆盖工作坊、图书馆、大纲、小组协作、看诊预约、问路、退换货、安检、餐厅订位、认知科学、环保碳中和、AI伦理、软技能、跨国周会、客户范围确认、敏捷周报、休假自动回复及软件采购。
- [x] **目标词义与正文语境一致性**：所有词汇表中列出的义项均为本篇课文句子中的具体义项（例如 draft 标注为“草稿/初稿”，而非“汇票”或“吃水深度”）。
- [x] **题目考查靶向性与选项唯一性**：每道题均有且仅有一个无可争议的正确答案，附有原文直接证据，所有干扰项均有明确的认知偏差成因解释。
- [x] **诊断分支的可区分性**：诊断短题与两套分支逻辑严格隔离，确保不同错误原因导向不同的学习路径，不发生逻辑死锁或混流。
- [x] **新语境验证无答案泄露**：验证题文本独立编写，实体名词、时间数字与选项排布完全重构，仅考查同类认知模型迁移。
- [x] **难度分级依据合理性**：A2、B1、B2难度评定均给出词汇、句式结构和认知任务三维解释，符合 CEFR 指标体系。
- [x] **音频脚本与制作标记**：听力题均提供可直接用于录音的标准英文 Script，且目标信息句与停顿点均清晰用方括号标出，统一注明“待制作音频”。

## 五、待审核事项与英语教研团队复核建议 (Pending Review Items)

为确保语料顺利导入 Flow 线上生产库，建议英语教研专家复核以下事项：

1. **音频录制与合成选配**：
   - `FLOW-PACK-001`（校园通知）：建议采用标准美音或英音女声，语速控制在 130-140 wpm，在数字 ten thirty 处保持自然的弱读与重音对比。
   - `FLOW-PACK-002`（门诊改约）：建议采用英音男女双人对话，女前台语气亲和礼貌，男患者在提出改约时带有适度迟疑的语调。
2. **版权许可正式备案**：
   - 标为 `待确认` 的材料（如借鉴自英国文化协会情境结构的 FLOW-CAND-001），当前文本已由AI进行全新事实重构与句式重写，在法律上属于独立衍生作品；但在平台大规模商业化推广前，建议法务团队进行常规版权清理或取得正式教学引用授权。
3. **知识点体系关联映射**：
   - 当前交付版本中，语法点与技能目标采用标准学术通用命名（如“一般现在时表示既定日程”、“转折信号词破立反差结构”）。Flow 教学产品团队可在后台直接将对应知识点映射至平台内部的 Knowledge Point ID 树状体系中。
4. **难度阈值动态校验**：
   - 建议在灰度上线初期，重点监控 `FLOW-PACK-001` 的 H1 与 H2 分流比例。若发现绝大多数错题学生均流向 H2（时间与活动混淆），可适当增加数字听辨的练习权重。
