# Flow 2.6 手机适配实现与检验

## 布局

mobile.css/js最后加载，沿用共享主题变量，不新建一套学习页面或状态。1050px以下保留导航抽屉和触控尺寸，760px以下显示底部快捷导航并使用手机单列布局，360px以下再缩紧间距。短横屏保留触控菜单与正常页面滚动。

底部导航调用现有data-view路由；更多按钮沿用setSidebarOpen。抽屉打开后main和底部导航置为inert，关闭后恢复触发按钮焦点。原有焦点循环、Esc关闭和离开页面的草稿保护保留。

手机图谱与桌面SVG共用同一组API节点、边、状态和导航动作。mobileGraphHTML不推测边，不把布局转为先修关系；普通详情最多展示8条，首页最多3条并默认折叠。小屏隐藏SVG而非缩小到不可阅读，桌面保留原图。

私教标签横向滚动，其他主体优先单列。图谱节点库允许局部纵向滚动，表格/代码块保留局部横向滚动。没有用overflow-x:hidden掩盖整页布局错误。输入控件保持16px，常用按钮至少44px；正文中的行内查词保持文字排版，选择题以整个label作为触控区域。

## 视口与键盘

沿用viewport-fit=cover，应用env(safe-area-inset-*)。mobileViewport观察visualViewport.resize和输入焦点，并同时保留未编辑时的高度基准，以兼容只缩小视觉视口及同时缩小布局视口两种情况。键盘出现时隐藏底部快捷导航，限制输入框占用高度并在必要时将其移入视口；不拦截正文输入或改写草稿。避免在viewport.scroll里反复触发scrollIntoView。

没有禁止用户缩放，没有新增媒体权限请求。朗读/麦克风继续使用原有实现及权限提示。

## 生产与测试

生产的认证、CSP、frame-ancestors和X-Frame-Options保持原规则。开发检查台仅在临时preview_server.py中使用模拟用户和同源iframe，以验证CSS视口；该开发文件、mock登录、检查台、package.json和启动包装脚本均不进入发布包。

浏览器检查了320/390/430手机宽度、768平板、1280桌面以及768×390短横屏。检查私教、图谱、语料库、词汇、复习、学习档案、设置、语法学习、测评的页面宽度，并逐步验证底部导航、抽屉、搜索弹窗、扩展词库选择例句、写作保存、私教工作区、登录和管理页。输入字段计算字号为16px，主要技能切换控件为48px，未发现整页横向溢出。

128项Python测试、13组Node界面测试通过。新增UI测试覆盖导航生成、真实关系列表、内容转义、键盘高度变化与抽屉隔离；独立升级包初始化检查覆盖静态资源安装。此次未做原生手机软键盘、音频硬件或所有浏览器实机测试，不将视口检查冒称为硬件验收。
