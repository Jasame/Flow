# Flow 2.2 UI 合并记录

以已交付的 Flow 2.1 为功能基线，将团队上传的 Flow-v0.7-Upgrade(1)(1).zip 中七个 public 前端文件的改版合入。未使用团队包中的旧后端、旧数据库逻辑或旧部署脚本。

## 界面整合

- 采用团队的系统字体、SVG品牌、通透侧栏、轻量工具栏、统一控件、阅读排版和浅/深/跟随系统外观。
- 保留团队的移动抽屉、键盘焦点、快速查找、原生弹窗、降低透明度与减少动态效果。
- 当前长期私教作为首页，知识图谱和AI词汇作为主导航；学习证据、本周进展、成长旅程、学习档案均保留。
- design-bridge.css 将上述新页面映射到共享设计变量，修正深色背景、文本、图谱节点与关系按钮；提高小字号可读性。
- 阶段任务以可展开的检查器列表呈现，热点区域在语料库中按需展开。Ctrl/Cmd+Enter同时支持私教与知识点导师输入框。

## 兼容保留

- 训练页面继续携带 coach_mission、定制任务要求、是否使用提示及反馈引用；打开材料和切换技能均调用服务端提示跟踪。
- 保留热点来源、语料审核状态、词汇关联、图谱跳转和原有作品版本。
- 保留个人调用无上限；移除旧UI包中的“每日20次”和null剩余次数文案。
- 合并团队的表单防重与禁用状态恢复、命名字段id兼容、草稿恢复、导航过期响应保护。
- 退出或账号切换清理新增私教、词汇、图谱、审核缓存与计时器。
- 请求标识优先使用 crypto.randomUUID，不支持时使用 crypto.getRandomValues 生成标准UUID，避免HTTP开发环境打不开训练页；服务端会话和CSRF机制不变。

## 验证

102项网站Python回归通过，9组Node前端检查通过，部署文件闭包与shell语法通过。

在隔离的Chrome桌面预览中检查了登录画面、私教首页、深色设置、证据、周报、知识图谱、词库、语料筛选入口、原文提示、听读写切换、写作草稿保存与作品档案。测试数据是可丢弃的UI夹具，不是生产数据。开发夹具、模拟身份与预览配置均不进入交付包。

本轮未验证真实Gemini内容、真实邮件、实体手机/平板、Safari或麦克风录音。团队包中的旧版浏览器矩阵是团队当时的记录，不作为本次合并版已通过的证明。浏览器扩展产生的环境日志不被表述成应用控制台零错误。

数据库结构继续为2.1兼容结构；站点健康版本为2.2，网关仍为2.0。无新依赖，无需更换密钥或重建数据库。
