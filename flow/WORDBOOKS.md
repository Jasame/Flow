# 专四、专八词书（英语专业）

**按考纲词汇量要求自编，不是官方词表。**

`corpus_data/wordbooks.json` 里有两本词书：`tem4` 专四词汇 6,146 词，`tem8` 专八词汇 4,892 词（不含专四已有的词，两本合计 11,038 词）。它们由 `tools/build_wordbooks.py` 只用仓库里已有的数据生成：没有复制任何书、网站或 App 的专四、专八词表（这些词表没有明确的许可），也没有下载新的数据。专四、专八没有官方公开的词表，ECDICT 也没有 TEM 标签，所以两本词书按考纲规定的词汇量自行选词。

## 词汇量依据

专四、专八考试检查学生是否达到《高等学校英语专业英语教学大纲》（高等学校外语专业教学指导委员会英语组编，2000 年）的要求，词汇量也以它为准：

| 级别 | 认知词汇 | 能正确熟练使用 | 出处 |
|---|---|---|---|
| 二级 | 4,000–5,000（含中学 2,000） | 2,000–2,500 | 《大纲》教学要求·词汇 |
| 四级（专四） | 5,500–6,500（含二级） | 3,000–4,000 | 《大纲》教学要求·词汇 |
| 六级 | 7,000–9,000 | 4,000–5,000 | 《大纲》教学要求·词汇 |
| 八级（专八） | 10,000–12,000 | 5,000–6,000 | 《大纲》教学要求·词汇 |

- 《大纲》全文（教学要求表中的“词汇”一行）：郑州财经学院外国语学院转载 <http://sfl.zzife.edu.cn/2019_11/06_00/content-19126.html>，江南大学数字化外语实验教学中心转载 <https://dletc.jiangnan.edu.cn/syjx/jxdg/yyzyjxdg.htm>。
- 《高校英语专业四级考试大纲》以 2000 年《大纲》为依据，“语法与词汇”部分要求掌握基础阶段认知词汇 5,500–6,000、熟练运用其中 3,000–4,000 个：<https://wy.gzist.edu.cn/__local/6/4E/34/03F0F6D05C84ABB597A3C9F68BB_04F84114_C400.doc>。
- 《高校英语专业八级考试大纲》检查学生是否达到《大纲》规定的高年级标准，本身不另列词汇量：<https://wy.gzist.edu.cn/__local/C/29/CB/23446C8B17D2E76B6B9425EA34A_4E4C97F3_7800.doc>。

于是：专四约 6,000 词（专四 6,146 词，加上不收的 150 个最常见词约 6,300，在 5,500–6,500 之内）；专四加专八约 11,000 词（八级 10,000–12,000 的中间）。

## 数据来源和许可

- **词频**：`corpus_data/yl-reference.json`，语流的参考词表（词频序号 1–20,200，见 `SOURCE-CORPUS.md`）。排序和频段都用它的序号。
- **考试标签、牛津 3000 标记、柯林斯星级、BNC / 当代语料库词频、义项行**：`corpus_data/ecdict-flow.json`，ECDICT（<https://github.com/skywind3000/ECDICT>，MIT 许可，Copyright (c) 2025 Linwei，全文见 `corpus_data/ECDICT-LICENSE.txt`）的子集，由 `tools/build_ecdict_subset.py` 提取。参考词表没有的考试词，排名取 ECDICT 的当代语料库或 BNC 序号。
- **收词**：`next_service.dictionary()`（`corpus_data/dictionary-flow.json`），即查词和背单词用的词典；每个词都必须在其中并有中文释义。选词只用它的收词、首字母大小写、排名和考试标签，不看释义文字，所以修订释义（`meaning-fixes.json`）不会让词进出词书。
- 选词规则由语流制定。JSON 的 `notice` 字段写明以上来源、许可和“不是官方词表”。

## 选词规则

**先排除**（对两本词书都适用，括号里是整个词典中被排除的词数）：

1. 不是纯小写单词、少于两个字母、没有中文释义或词典里首字母大写的词（328），与现有词书 `vocab_service.book_words()` 的规则相同；
2. 词频前 150 的词（136，其余已被上一条排除）：the、be、of……，与基础词汇书跳过的 `CORE_SKIP` 相同；
3. 没有词频数据的词（1,368）：ECDICT 中既无当代语料库也无 BNC 排名（排名记作 30,000 及以上）；
4. 专有名词（62）：月份和星期（march、may、august 另有普通义，保留）、christ、atlantic、pacific、fahrenheit；ECDICT 不保留大小写，所以参考表之外的词若没有柯林斯星级、牛津标记和当代语料库排名，又只有名词义项，按地名人名处理（london、france、sydney），`COMMON` 里列出的几个普通名词（bacterium、quart、ohm 等）除外；
5. 只有缩写（4）、感叹词（24，oh、hello、alas）、俚语或方言（6，yup、biz）义项的词，粗俗词（14）；
6. 只有专业领域释义的词：ECDICT 中只有 `[计]`、`[医]` 这类领域行、参考表也没有普通释义；
7. 考试词表没有的两字母词（19，em、ya、vs）；
8. 词形变化（181 + 5）：释义注明“某词的过去式、复数、最高级……”而原形已在词典里、自己又没有独立义项的（increased、closest、lots、chosen）；有独立义项且被考试词表收录的保留（found 建立、lost 迷惑的、being 存在）；没有考试标签又只有动词义项的 -ed/-ing 形式（elected、solving）；
9. 由已收词组成、考试词表都不收的连字符复合词（523，long-term、twenty-five、face-to-face）；
10. 同一个词的两种拼写只留一种（52）：colour/color、centre/center、realise/realize、towards/toward、whilst/while 等，留参考表里更常用的那种，它继承另一种拼写的考试标签和牛津标记。

**专四（`tem4`）**：剩下的词中满足任一条：

- 参考词表词频序号 151–5,000（4,115 词）；
- 四级词，不论词频（再加 1,196 词：pronoun、plural、punctual 这类课本词在当代语料里排得很靠后）；
- 六级词且排名不超过 8,000（再加 601 词）；
- 牛津 3000 核心词（再加 234 词：dictionary、umbrella、passport）。

**专八（`tem8`）**：剩下的词中不在专四、且满足任一条：

- 参考词表排名不超过 10,000（2,466 词）；
- 六级词或考研词，不论词频（再加 712 词：haughty、obstinate、hitherto）；
- 雅思、托福、GRE 词且排名不超过 16,000（再加 1,714 词：ubiquitous、grandiose、exonerate）。

**顺序**：两本都按词频从高到低（排名数字从小到大，最常用的在前），同排名按字母。`TEM4_FREQ`、`TEM4_CET6`、`TEM8_FREQ`、`TEM8_EXAM` 四个阈值写在 `build_wordbooks.py` 开头，是按上面的词汇量目标调出来的：专四在 6,000 左右（5,000/8,000 时 6,146；4,500/8,000 时 6,034；5,000/10,000 时 6,438），合计在 11,000 左右（10,000/16,000 时 11,038；10,000/14,000 时 10,431）。

## 已知局限

- 参考词表偏美国当代语料（新闻、口语），一些课本常见词排得很靠后。四级词全部收入专四弥补了这一点，但这些词在专四末尾。
- 六级、考研词全部收入，所以专八末尾有一批老旧的理工科词（capacitor、ohm、metallurgy）。
- 专有名词、词形变化和拼写变体的判断是规则加少量名单，个别词可能误判；首字母大写的词（如词典里写成 Supreme、Polish 的 supreme、polish）按现有词书规则不收。
- 释义来自 ECDICT，部分常用词第一个义项不是最常用的（keep 先列“n. 生计”）。修订释义走 `meaning-fixes.json`，不影响选词。

## 重建和检查

```bash
python3 tools/build_wordbooks.py          # 重建 corpus_data/wordbooks.json，打印词数和重合度
python3 tools/build_wordbooks.py --check  # 文件与重新生成的结果不同时退出码为 1
```

改了词频表、ECDICT 子集、词典收词或选词规则后重建并一起提交。`tests/test_wordbooks.py` 检查格式、标题和分组、无重复、两本不重叠、每个词都在词典里且有中文释义、词数在上面的范围内（专四 5,500–6,500，合计 10,000–12,000）、顺序，以及文件与重新生成的结果一致。

文件格式（应用按它读取）：

```json
{"notice": "来源和许可",
 "books": {"tem4": {"title": "专四词汇", "group": "英语专业", "blurb": "选词书时的一行说明",
                    "basis": "一两句中文：怎么编的，按考纲词汇量，不是官方词表", "words": ["put", "old", "..."]},
           "tem8": {"title": "专八词汇", "group": "英语专业", "blurb": "…", "basis": "…", "words": ["..."]}}}
```

`words` 是学习顺序（最常用的在前），都是词典的小写词形。
