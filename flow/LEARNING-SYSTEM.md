# 学习系统评估与重构方案（r14）

写给以后改这套系统的人：先说现在的学习流程哪里对、哪里有问题，再说依据哪些学习科学的结论、针对中文母语者做了什么，最后说为什么这样重构、不那样重构。

## 一、现状评估

**已经做对的：**
- 一条主线：今日一篇 → 听 → 读 → 理解 → 用出来 → 复习自己收藏的。输入在前、输出在后，符合“可理解输入 + 推动输出”。
- 单词和表达用 FSRS 安排复习（检索练习 + 间隔重复），复习时挖空原句，不是孤立的单词卡。
- 证据模型把“做题做对”“读到过”“AI 意见”分开记录，不把复读当成掌握。
- 知识图谱把语法点和真实材料连起来，44 个点各有讲解页和 10 道验证题。

**问题（这一轮要解决的）：**
1. **复习会陷入循环。** 理解题做错后变成一张复习卡，但复习时只有题目、没有原文——答不出来只能再错；错了 1–10 分钟后又回来，同一轮可以无限次出现。改错卡要求一字不差，写法不同但意思对也算错，又是一轮。
2. **错题卡没有终点。** 理解题这类“一次性”的东西被当成单词一样永远按遗忘曲线复习，越积越多。
3. **语法练习是“分块”的。** 每次只练一个点的 4 道题，做完就会，过两天又忘；研究上，把几个点混在一起练（交错练习）记得更牢，也更像真实使用。
4. **知识图谱是一张清单。** 点和点之间的关系（先学什么、和谁容易混、常和谁一起出现）只在详情页底部有一两个小标签，看不出路线。
5. **不够灵活。** 每天新词最多 30 个，学完当天的就没法多学；每天时长只有 4 档。
6. **鼓励不够具体。** 做完只说“完成了”，没告诉学习者这次具体进步在哪。

## 二、依据的学习科学原则，以及在 Flow 里怎么落地

| 原则 | 意思 | 在 Flow 里 |
|---|---|---|
| 检索练习 | 主动回想比再看一遍记得牢 | 复习都要先答再看答案（已有） |
| 间隔重复 | 在快忘的时候复习 | 单词用 FSRS；语法点按 1/3/7/21/60 天复查（r13） |
| 交错练习 | 几类题混着练，逼自己先判断“这是哪一类” | **新：语法混合复习**，每天把到期的几个点各抽一两题混在一起 |
| 变式练习 | 同一规则换不同的题，考规则不考记忆 | **新：语法错题每次换同一知识点的另一道题** |
| 对比分析 / 母语迁移 | 错误多来自母语习惯，把差别说破最有效 | **新：每个语法点的“中文思维陷阱”**：中文怎么说 → 常见错误 → 正确说法 |
| 辨析 | 易混的两个点放在一起练 | **新：易混点辨析练习**，33 组 |
| 情境中学习 | 意义在原文里，脱离原文的题没有意义 | **新：理解题错题带原文段落** |
| 期望难度，但要能完成 | 太难会放弃，太易没收获 | 每张卡当天最多错两次，之后明天再来；每天的计划有终点 |
| 胜任感（自我决定理论） | 看得见进步才愿意继续 | **新：结果页说清进步**（点亮了哪些点、下次复习在几天后），不做排行、不罚断签 |

## 三、针对中文母语者

中文母语者的错误高度集中，而且多数来自中文的结构：
- **形态**：中文动词不变形，名词没有单复数 → 第三人称 -s、过去式、复数、可数/不可数最容易错；
- **冠词**：中文没有冠词 → 漏 a/the，或把“这个”套成 the；
- **语序**：中文修饰语在名词前 → 定语从句、宾语从句语序；
- **成对连词**：虽然…但是、因为…所以 → although…but；
- **语气代替语法**：中文靠语气表示假设和推测 → 虚拟语气、情态动词；
- **主题句结构**：“这本书我看过了” → 被动与主语选择；
- **怕出错、少开口**：低压力、私下的输出练习（跟读、AI 改写）比当众练习更有效。

所以每个语法点加了一条“中文思维陷阱”，用一句中文、一个典型错误、一个正确说法把差别说破；易混点的辨析也优先选中文母语者最常混的组合（过去时/完成时、must/can't、although/despite、boring/bored……）。

## 四、要不要整体重构

**结论：不推倒重来，按“学习对象的生命周期”重构复习和错题，图谱加一层关系。**

- 推倒重来的代价：现有证据模型、FSRS、四步学习流程、240 篇校验过的材料和 700 多项测试都是对的，重写只会丢掉这些。
- 真正的问题不在架构，而在几类学习对象被用了同一套规则。现在按对象分开：

| 对象 | 规则 |
|---|---|
| 单词、表达 | FSRS 间隔重复，直到熟练（不变） |
| 理解题错题 | **一次性**：带原文重做；答对就“过关”退出；再错就给出原文依据并建议重读，然后也退出 |
| 语法错题 | **变式**：每次换同一知识点的另一道题；连续两次答对就退出，之后交给语法点的复查 |
| 写作改错卡 | FSRS；写法不同时可以自己判断“意思一样”，不再因为一字之差判错 |
| 任何卡 | 当天答错第二次后，改到明天（每天有终点，不会循环） |

- 知识图谱：在“先学”关系之外加“易混”和“常一起出现”，新增“学习路线”视图（像地铁线一样按顺序连起来，一眼看到下一站），详情页用一张小关系图串联前后和左右。
