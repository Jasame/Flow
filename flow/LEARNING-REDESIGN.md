# Flow 3.0 学习系统修改方案与实施记录

## 目标与验收原则

让知识图谱连接知识、实际表现和下一步行动。默认入口回答：我卡在哪里，为什么先练这一项，练后怎样验证。保留用户原计划和主动选择；提交、XP、AI意见、独立通过分别记录。此次完成第一阶段可部署实现，同时为需要真实语音、教师审校及长期用户数据的工作明确后续验收条件，不将其声称为已完成。

## 十二项问题的处理

| 问题 | 3.0 实际修改 | 后续验收与限制 |
| --- | --- | --- |
| 图谱目的不明 | 改为英语能力地图；首页优先显示补练或续学，关系网折叠为探索 | 用真实学习者检验是否能解释自己下一步，不以节点数量衡量价值 |
| 连线语义混杂 | 八类关系分别提供连接原因、可采取行动、含义边界与已有来源；可进入两端节点 | 当前是对保存关系的规则解释，不证明公共词义或教学先修绝对正确 |
| 图谱与计划脱节 | 错误、提示后作答优先产生首页补练；听读失败推荐平行情境；保留继续原计划入口 | 未建立自动归因到音素、词义或句法的诊断，单次错误不推断原因 |
| 掌握状态共享 | 搭配使用自身节点证据；单词引用义项时标明范围；词义理解与拼写只有同类检查才能形成延迟/迁移证据 | 搭配尚缺独立题时保持未知，不伪造通过 |
| 提交等于学会 | 旅程显示已参与、需补练、已有独立证据；首页插入补练 | 完成仍记录参与和XP，不把答错改成未参与；不是强制闯关 |
| 分级题与正文脱节 | 108份新题组版本；B1补充新增段落的原因/条件，B2考查观点、限制和过度推断；旧版本不再自动推荐 | A2仍为事实理解；每篇仍两题，非标准化测评，需教师审题与真实作答分析 |
| 答案暴露 | 同情境理解题重复或跨技能作答标记熟悉题；语法题近24小时重复标记熟悉练习；保留所有作品 | 只追踪系统内可观察行为，不声称杜绝外部查答案；同情境处理较保守 |
| 起点与升降档不稳 | 起点由8题增至12题，听读增加样本；独立理解达到六个不同情境才调整；5/6通过升档，≤2/6降档；保存确认档位 | 仍是教学建议，不是CEFR认证；尚未建立经验证的测量模型 |
| 六维配比固定 | 保留六维底线，补练优先；词汇/语法3分钟、听读5分钟、口语6分钟、写作10分钟，按个人预算拆单元；听读使用平行情境并分别匹配建议档位 | 用时是可调整估计；周训练比例与真实耗时反馈仍需后续实施 |
| AI反馈没有吸收过程 | 反馈带入同一材料技能的最近已保存原稿与一项旧建议，要求先修改再看范例；允许没有纠错项；保留原稿修订链 | 模型建议需核对；跨语境独立表达与长期错误复发评价尚不能仅凭AI认定 |
| 口语与长期素材不足 | 录音转写、反馈、追问和保存继续可用；与旧稿比较有教学背景，内容版本与情境组分别统计 | 本次没有实现实时双向语音、可靠发音评测或新增真实新闻/长篇体裁，不冒充完成 |
| 多个入口相互竞争 | 私教首页建立优先行动：知识补练→听读平行情境复练→原单元→下一阶段；图谱提供依据 | 私教文本有生成不确定性，需要真实Gemini验收，发现冲突可通过学习档案纠正 |

## 版本与数据策略

- 原154份材料全部保留，新增108份修订题组，数据库合计262个材料版本；自动推荐默认使用154份当前教学版本、82个情境组。新增版本不代表新增108个独立情境。
- 修订版本ID在旧ID后加 `-r30`，记录 `revision_of`，共用原情境family。旧作品、答案、笔记、草稿、收藏不改写。旧版收藏/草稿仍可进入；历史作品可回到原材料。
- 旧学习事件不删除。新规则重新汇总后，搭配、延迟与迁移状态可能降低，这是纠正此前证据范围过宽，不是清空学习进度。
- 新建practice_calibration表保留听读建议档位；学习者长期未使用后，不因14天样本窗口为空而直接退回起点。
- 无新增个人Gemini每日调用次数上限；图谱解释、调度和统计不额外调用模型。现有2.0网关不变。

## 后续实施顺序

1. 教师审校题目与干扰项，使用答题数据检查题目是否真能区分理解层次；每篇增加不同目标题，不用更多相似题凑数。
2. 建立词义、搭配、语法的独立任务，优先覆盖真实高频错误；基于新题和跨语境作品评价吸收，而非只改变图谱颜色。
3. 记录学习者确认的真实耗时、完成负担与每周重点，调整六维比例；允许疲劳时缩成小任务。
4. 另行接入并验收实时口语回合、澄清任务和音频质量。独立验证可理解度后再考虑发音反馈，不根据转写生成发音分数。
5. 分批增加有清楚来源和授权的对话、邮件、长文、演讲与学术体裁，并维持难度、题目、语域和来源审校。

## 使用者验收

用一个有真实错误的账号完成“首页补练→提交→返回原计划→图谱追溯”；用另一个账号确认互不可见。检查听力先答后阅读与重复作答均不冒充新独立证据。抽查每级新题的证据段落与正确选项；隔天复测同一能力，检查理解与拼写没有互相替代。最后用真实Gemini和手机设备验收文字建议、录音和系统朗读。
