# 用免费 Apple 账号把「语流内测」装到自己的 iPhone

不用付费开发者账号也能装，只是每次装好能用 7 天，到期连上电脑再装一次就行。全程大约 15 分钟。
标着 **👉 你来点** 的步骤要你自己操作：Apple ID、密码、验证码只在你自己的 Xcode 和手机上输入，不要发给任何人（包括 Claude）。

## 准备

- 这台 Mac（已经装了 Xcode）、你的 iPhone、一根能传数据的线。
- 一个 Apple ID（就是你手机上登录的那个就行）。
- 代码放在一个不会被删掉的文件夹。在「终端」里运行（只需要第一次）：

```bash
git clone https://github.com/Jasame/Flow.git ~/Developer/Flow
```

  以后更新：

```bash
git -C ~/Developer/Flow pull
```

## 第 1 步：在 Xcode 里登录 Apple ID（只需要一次）

1. 打开 Xcode。
2. **👉 你来点**：菜单 Xcode → Settings（设置）→ Apple Accounts（账户）→ 左下角「+」→ Apple ID → 输入你的 Apple ID 和密码（以及手机上弹出的验证码）。
3. 登录后左边会出现你的账号，右边能看到「(Personal Team)」。

## 第 2 步：告诉项目用你的免费团队（只需要一次）

**👉 你来运行**：在「终端」里运行下面这一行，最后的 `lx` 换成你的名字缩写（字母或数字）：

```bash
sh ~/Developer/Flow/ios/tools/personal-team.sh lx
```

它会找到你在 Xcode 里登录的「Personal Team」，写进 `ios/Config/Local.xcconfig`（只在这台 Mac 上，不上传）。
App 的标识会是 `cn.flowlang.app.beta.lx`：原来的 `cn.flowlang.app.beta` 留给以后的付费账号，免费账号用过的标识，付费账号可能就用不了了。
看到「好了」就可以了。如果说还没有登录，回到第 1 步。

然后在「访达」里双击打开 `~/Developer/Flow/ios/Flow.xcodeproj`。左边点最上面蓝色的「Flow」→ TARGETS「Flow」→「Signing & Capabilities」，应该能看到你的团队，没有红色错误。
（如果有 “Failed to register bundle identifier”，把缩写换一个，重新运行上面那一行。）

## 第 3 步：手机打开「开发者模式」（只需要一次）

1. 用数据线把 iPhone 接到 Mac，手机上如果问「要信任此电脑吗」，点「信任」，输入手机密码。
2. **👉 你来点**：iPhone「设置 → 隐私与安全性」，拉到最下面「开发者模式」→ 打开 → 按提示重启手机 → 重启后再点「打开」。
   （看不到「开发者模式」的话，先做完第 4 步的第 1、2 小步，它就会出现。）

## 第 4 步：装上去

1. Xcode 窗口最上面中间，scheme 选「Flow-Beta」，右边的设备选你的 iPhone（名字就是你手机的名字）。
2. **👉 你来点**：点左上角的 ▶（运行）。第一次会比较慢，Xcode 可能会问是否允许访问钥匙串，输入 Mac 的登录密码并点「始终允许」。
3. 第一次装完，手机上点图标会提示「不受信任的开发者」：
   **👉 你来点**：iPhone「设置 → 通用 → VPN 与设备管理」→ 点你的 Apple ID → 「信任」。
4. 再点手机桌面上的「语流内测」图标，就能用了。打开的是内测版 flow.jasa.hk，账号和网页版的内测版是同一个。

## 用起来试试这些

- **整篇朗读**：打开一篇有录音的文章，点「播放全文」，然后锁屏——声音应该接着放；锁屏界面上有「语流 · 标题」，能暂停、继续、上一句、下一句。
  （这一条要等网页那一侧的改动合进内测版；合进去之前，App 里的「播放全文」还是网页自己放。）
- **来电或别的 App 打断**：放的时候打个电话进来，挂了以后应该自己接着放。
- **录音**：第一次录音时手机会问能不能用麦克风，选「允许」。
- **复习提醒**：在「单词」里点「加到手机日历」，App 会问「用 App 通知提醒 / 加到系统日历」，选通知并允许，到点会收到「该复习单词了」。

## 7 天以后

免费账号装的 App 7 天后会打不开（显示「无法验证 App」）。连上电脑、打开 Xcode、点 ▶ 再装一次就好，数据和登录都还在。

## 什么时候该办付费开发者账号

想给别的同学装、或者不想每 7 天重装一次的时候，就该办 Apple Developer Program 了：

- 网址 developer.apple.com/programs，每年 99 美元（人民币按 Apple 当时的价格），**👉 你来办**：用你自己的 Apple ID 登录，个人身份要实名（中国大陆一般要身份证信息和人脸验证，用 Apple Developer App 办最顺）；以公司名义办需要邓白氏编码（D-U-N-S）。
- 办好以后告诉我（语流 20），我把 TestFlight 的步骤接着做：先你自己内部测试，再开外部测试给试用同学。
- 以后要在 App Store 中国区上架，还要先做 App 备案（和网站的 ICP 备案主体一致），这个到时候再办。
