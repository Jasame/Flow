# 语流桌面版：安装和第一次打开

语流桌面版现在是**内测**阶段，安装包还没有经过苹果和微软的签名认证，所以第一次打开时系统会拦一下。
下面说怎么放行。放行一次就好，以后直接打开。

> 「语流内测」打开的是内测版（flow.jasa.hk），账号和数据跟正式版分开；「语流」打开正式版（flowlang.cn）。两个可以同时装。

---

## Mac

**要求**：macOS 11 或更新，Apple 芯片（M1 及以后）和 Intel 都可以。

1. 双击下载好的 `语流内测_….dmg`，把「语流内测」拖到「应用程序」文件夹。
2. 打开「应用程序」，双击「语流内测」。会弹出提示：**“无法打开「语流内测」，因为 Apple 无法检查其是否包含恶意软件”**（或「无法验证开发者」）。点「完成」或「好」关掉。
3. 打开 **系统设置 → 隐私与安全性**，往下拉到「安全性」，能看到 **“已阻止「语流内测」以保护 Mac”**，点旁边的 **「仍要打开」**。
4. 输入 Mac 的登录密码（或按指纹），再点一次 **「仍要打开」**。之后就和普通 App 一样了。

> macOS 14 Sonoma 及更早也可以这样放行：在「应用程序」里**按住 Control 点按**（或右键点）这个 App，选「打开」，再点「打开」。从 macOS 15 起这个办法不再管用，只能走上面的「系统设置」。

**如果提示「已损坏，无法打开」**：这是下载时被打上了「来自互联网」的标记。打开「终端」，粘贴下面这行再回车（要输入 Mac 的登录密码，输的时候不显示）：

```
sudo xattr -dr com.apple.quarantine "/Applications/语流内测.app"
```

**第一次用会问的权限**：

- **通知**：在「单词 → 调整计划」里点「到点用 App 通知提醒」，或者菜单栏「语流内测 → 复习提醒用系统通知」，Mac 会问一次，点「允许」。以后在 系统设置 → 通知 → 语流内测 里改。
- **麦克风**：第一次跟读、口语练习时 Mac 会问，点「允许」。只在你点录音的那几秒打开。

## Windows

**要求**：Windows 10 或 11（64 位）。

1. 双击下载好的 `语流内测_…_x64-setup.exe`。
2. 会弹出蓝色窗口 **“Windows 已保护你的电脑”**（Microsoft Defender SmartScreen）。点文字里的 **「更多信息」**，再点出现的 **「仍要运行」**。
3. 安装程序很快就装好（装在你自己的用户目录下，不用管理员密码），开始菜单和桌面会有「语流内测」。
   - 如果电脑上没有 WebView2（Windows 10 老版本才可能没有），安装程序会自动下载装上，要联网。
4. 以后从开始菜单打开就行。

**浏览器下载时也可能拦一下**：Edge 可能在下载栏里提示「不常下载」。点 **「…」 → 「保留」 → 「显示详细信息」 → 「仍然保留」**。

**右下角的托盘图标**（任务栏右边，可能在「^」里面）：右键可以

- 打开语流内测
- 复习提醒用系统通知（打勾后，到点弹 Windows 通知，App 关着也会弹）
- 开机时启动（默认不开）
- 关窗口后留在托盘（默认关窗口就退出）
- 发一条测试通知（看看通知能不能弹出来）

如果通知没弹：打开 **设置 → 系统 → 通知**，找到「语流内测」打开；「专注」或「勿扰」开着时通知也会被收起来。

---

## 以后的新版本

从 0.1.1 起，「语流」会自己更新：打开后在后台下载新版本，关掉时装上，下次打开就是新版。也可以在菜单（Mac）或托盘（Windows）里点「检查更新…」马上装。
0.1.0 还不会自己更新，请从下载页手动装一次新版。Mac 上请把「语流」放在「应用程序」文件夹里，直接从下载文件里打开的话更新装不上。

## 卸载

- **Mac**：把「应用程序」里的「语流内测」拖到废纸篓。
- **Windows**：设置 → 应用 → 已安装的应用 → 语流内测 → 卸载。

卸载只删除 App 本身；你的学习记录在账号里，换电脑、用网页版登录还在。
