# 把语流装到安卓手机上

现在还没上应用商店，要用安装包（APK）直接装。不需要任何账号，大约 2 分钟。

## 1. 选安装包

| 文件 | 装好后的名字 | 打开的网站 | 从哪里拿 |
|---|---|---|---|
| `flow-beta-<版本>.apk` | 语流内测 | flow.jasa.hk（内测版） | GitHub → Jasame/Flow → Actions →「Android」→ 最新一次 main 的 run → 下载 `flow-beta-apk`（zip，解压出 APK）。每次合进新改动都会打一个新的，留 30 天 |
| `flow-<版本>.apk` | 语流 | flowlang.cn（正式版） | 语流 C2 在你的 Mac 上打好给你 |

两个可以同时装。内测版和正式版的账号是分开的。

## 2. 把安装包传到手机上

任选一种：

- **网盘**：在电脑上把 APK 传到网盘，再用手机打开网盘 App 下载。
- **微信或 QQ**：发到「文件传输助手」，在手机上点开下载。如果文件名变成了 `.apk.1`，或者提示不能打开，就换网盘。
- **数据线**：连上电脑，把 APK 拷到手机的「下载」文件夹。Mac 要先装一个安卓传文件的工具（比如 OpenMTP）。

## 3. 安装：这几步要你自己点

1. 在手机上点开 APK（在「文件管理」的「下载」里，或者在网盘、微信里直接点）。
2. 第一次装时，手机可能提示**「出于安全考虑，您的手机目前不允许安装来自此来源的未知应用」**。点**「设置」**，打开**「允许从此来源安装应用」**（有的手机叫「允许来自此来源的应用」或「安装未知应用」），然后返回。有的手机会先提醒一句未知应用的风险，点**「继续」**。
   - 这个开关是给「用来打开 APK 的那个 App」开的，比如文件管理、浏览器或微信。装完以后可以再关掉。
3. 点**「安装」**。各品牌手机还会多问一句，按下面选：
   - **华为、荣耀**：如果提示「纯净模式」，选「仍然安装」，或者先在设置里暂时关掉纯净模式。
   - **小米、红米**：如果出现安全提示，等倒计时结束，再点「继续安装」。
   - **OPPO、一加、realme**：如果提示「未经检测」，勾选「已了解风险」，再点安装。
   - **vivo、iQOO**：可能要输入 vivo 账号的密码。
   - **装了谷歌服务的手机**：如果「Play 保护机制」提示「未知的应用」，点「仍然安装」。
4. 装好以后，桌面上会出现绿色图标「语流」或「语流内测」。

> 华为纯血鸿蒙（HarmonyOS NEXT，也就是鸿蒙 5 以上不再兼容安卓的版本）装不了 APK。

## 4. 第一次打开

- **登录**：用你在网站上的账号。登录一次以后，下次打开 App 还是登录状态。
- **麦克风**：第一次录音时会问能不能用麦克风，选**「仅在使用该应用时允许」**。App 自己从不打开麦克风，只在网页要录音时才打开。
- **复习提醒**：在「单词 → 计划」里点**「到点用 App 通知提醒」**，然后在弹窗里点**「允许」**。
  - 想让提醒准点：Android 14 以上的手机，到「设置 → 应用 → 语流 → 闹钟和提醒」里打开。不打开也能提醒，只是可能晚到，最多晚 10 分钟。
- **锁屏听全文**：放全文（「听」的播放全文、「读」的伴读）的时候可以锁屏，声音接着放。锁屏和通知栏上会显示文章标题和「AI 朗读 · 第几句」，可以暂停、上一句、下一句。来电时会暂停，挂了电话自己接着放。
  - 如果锁屏一会儿声音就停了，可能是手机在省电。到「设置 → 应用 → 语流 → 耗电（或电池）」里，选「不限制」或「允许后台活动」。华为、小米、OPPO、vivo 的手机常常要这样设一下。

## 5. 升级和卸载

- **升级**：从 1.0.2 起，打开语流时如果有新版本，会弹出「有新版本 x.y.z」，下面写着这一版改了什么。
  - 点**「下载」**：语流会下载新的安装包并核对，然后手机会问「要更新此应用吗？」，点**「更新」**（有的手机叫「安装」）。登录和学习进度都还在。
  - 第一次在 App 里更新时，手机会要你允许语流「安装未知应用」：按提示点「去设置」，打开「允许从此来源安装应用」，再返回。
  - 点**「稍后」**，这一版当天不再提醒，第二天打开时会再提醒。
  - 直接装的 App 没法自己悄悄更新，每次都要你点一下「更新」。
  - 1.0.1 及更早的版本还没有这个功能：到 flowlang.cn/download 下载新的 APK，直接装，会覆盖旧版本，登录和学习进度都还在。
  - 内测版从 Actions 拿的新包，总能覆盖上一个。
- **卸载**：长按图标，选「卸载」。
